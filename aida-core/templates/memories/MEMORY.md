# Project Memory Index

This file indexes the project's persistent memories — one fact per file,
each loaded into context at session start so the index stays small.

The block below is the **AIDA starter discipline pack** — generic guidance
on working effectively with AIDA, scaffolded by `aida init --with-memories`.
Add your own project memories outside the markers; everything outside the
`aida:scaffold-pack` block is yours and is never touched by a refresh.
`aida init --with-memories --refresh` regenerates only the block between the
markers, and only for pack files you have not edited.
