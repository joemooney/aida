# Contributing to AIDA

For using AIDA on your own project, start with the
[adopter documentation](docs/README.md#im-using-aida).

To develop AIDA itself, read [AGENTS.md](AGENTS.md) for repository instructions,
[OVERVIEW.md](OVERVIEW.md) for architecture, and the
[contributor documentation](docs/internal/README.md) for design, tests, plans
and documentation maintenance. Requirements live in AIDA; read the owning spec
before making a change and include its ID in code traces and commit trailers.

Follow the [repository guide](docs/internal/agents/aida-repository-guide.md)
for build and test commands, and the
[developer CLI reference](docs/cli/11-dev.md) for local builds and releases.
