What is AIDA?

AIDA is a requirements management system built for modern software development workflows.

Key Features

  • Multiple Views - List, Kanban, Timeline, Sprint Planning, Org Chart
  • AI Integration - Requirement evaluation and Claude Code skills
  • Keyboard-First - Vim-style navigation throughout
  • Code Traceability - Link code to requirements with inline comments
  • Flexible Organization - Features, relationships, custom types

AIDA supports multiple requirement types for different methodologies.

🎯 Epic (EPIC)

✅ Task (TASK)

Code Traceability

Link your code directly to requirements with inline trace comments.

Trace Comment Format

// trace:FR-0042 | ai:claude:high
fn implement_feature() {
    // Implementation linked to requirement
}

Components

FieldDescription
trace:SPEC-IDRequirement being implemented
ai:toolAI tool used (claude, copilot)
:confidencehigh, med, or low

Language Support

// Rust, JavaScript, C++
// trace:FR-0042 | ai:claude:high

# Python, Shell
# trace:FR-0042 | ai:claude:high

<!-- HTML -->
<!-- trace:FR-0042 | ai:claude:high -->

Confidence Levels

  • high - >80% AI-generated
  • med - 40-80% AI with modifications
  • low - <40% AI, mostly human

Command Line Interface

Full-featured CLI for scripting and automation.

Basic Commands

# List requirements
aida list
aida list --status approved
aida list --type Bug

# Show details
aida show FR-0042

# Add requirement
aida add --title "New feature" \
    --description "Details..." \
    --type Functional \
    --status Draft

Advanced Commands

# Edit requirement
aida edit FR-0042 --status completed

# Add relationships
aida rel add --from FR-0001 \
    --to FR-0042 --type Parent

# Add comments
aida comment add FR-0042 \
    "Implementation note..."

# Export
aida export --format markdown
Tip: Use CLI in CI/CD pipelines to validate requirements or generate reports automatically.

Multi-Project Support

Manage multiple projects from a single AIDA installation.

Project Registry

  • Register projects - Add projects to your registry
  • Quick switching - Switch between projects instantly
  • Default project - Set a default for CLI commands
  • Auto-detection - Find requirements.yaml in current directory

Storage Options

  • YAML - Human-readable, git-friendly (default)
  • SQLite - Better performance for large projects
# Switch projects
aida project switch my-project

# List registered projects
aida project list

Getting Started

Installation

# Build from source
git clone https://github.com/joemooney/aida
cd aida
cargo build --release

# Run GUI
./target/release/aida-gui

# Run CLI
./target/release/aida --help

Quick Start

  1. Launch aida-gui
  2. Create a new project or open existing
  3. Press a to add first requirement
  4. Press ? to learn keyboard shortcuts
  5. Scaffold Claude Code integration from Settings
