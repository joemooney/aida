01 / ARCHITECTURAL CAPABILITIES & ENFORCED INVARIANTS

28 Repository-Verified Engineering Mechanisms

Every capability below is implemented in the AIDA Rust workspace and exposed through the live CLI. Each row links the architectural invariant to its exact CLI entry point, owning crate, and verified source module.

Capability / Engineering Mechanism CLI Command Owning Crate & Source Module Enforcement Boundary Operational Guarantee
Orphan-Branch Git-Canonical Spec Store (aida-store)
Specs live on an orphan Git branch with per-object YAML/JSON files and union-merge conflict resolution—never polluting code PR diffs.		 aida store aida-core/src/object_store.rs Store Writer Lock Zero spec-file merge conflicts on product code branches; atomic per-object updates.
Offline Hierarchical ID Block Allocation
Tree-ordered CAS block dispenser (enroll-root, upstream, hub) lets offline or air-gapped clones mint collision-free sequential IDs.		 aida node acquire aida-core/src/block_allocation.rs CAS Ref Dispenser Collision-free requirement IDs across disconnected clones without a central database server.
Pre-Registered Hypothesis Locking
Automatically seals hypothesis-tagged spikes/decisions (hypothesis_lock SHA + timestamp) once a linked neighbor completes.		 aida edit aida-core/src/hypothesis.rs Canonical Store Gate Prevents post-hoc editing of pre-registered hypotheses; survives tag/link removal or reopening.
Transitive Spec Dependency & Reverse-Impact Graph
Walks epic trees, transitive BlockedBy/Blocks chains, and reverse-impact blast radius with cycle rejection.		 aida graph impact aida-core/src/graph_walk.rs DAG Cycle Check Computes upstream/downstream spec impact and epic completion rollups deterministically.
Inline 30s SQLite History & FTS Catch-Up Cache
Derived SQLite query/history index catches up incrementally via IndexLock without blocking Git readers or spawning on commits.		 aida cache refresh aida-core/src/storage.rs IndexLock (30s Budget) Fast full-text and history queries while keeping the Git orphan branch as sole source of truth.
Reopen SHA Fencing Against Stale Merge Credit
Records reopened_at_sha when a Completed spec is reopened so old commits on main cannot auto-close it again during pull/reconcile.		 aida db reconcile-status aida-cli-lib/src/db_reconcile.rs SHA Fence Check Prevents historical merge evidence from prematurely closing reopened requirements.
5-Rung Per-Spec Autonomy Ladder + Monotonic Override Guard
Every spec selects operator, guided, drive, drain, or decide; loosening human oversight requires --force and decide is non-overridable.		 aida do · aida autonomy aida-cli-lib/src/autonomy_cmd.rs Per-Spec Contract Matches execution autonomy to spec risk class; blocks unattended runs on supervised specs.
OS-Level Agent Sandbox Containment (bubblewrap / Landlock / Cgroups)
Enforces read-only source mounts, credential blackholing, network namespace isolation, and cgroup v2 memory/PID caps per agent role.		 aida agent new aida-cli-lib/src/contained_boundary.rs Linux Kernel Jail Confines untrusted or role-scoped agent processes at the OS boundary.
Seat Occupancy (C7) & Process-Bound Grant Delegation
Validates caller authority under seat locks, binds grants to child process trees, and revokes stamped child grants upon worktree lease cleanup.		 aida role expiry aida-cli-lib/src/role_cmd.rs Locked Seat Roster Ensures delegated child agents expire with their parent grant and cannot outlive their lease.
Sandboxed Advisor Dispatch Queue & Terminal Deputy
Sandboxed advisor sessions enqueue typed requests (flow, review, take, impl) executed by a human-granted terminal deputy.		 aida dispatch · aida deputy aida-cli-lib/src/dispatch.rs Typed Request Queue Separates advisor planning/routing from privileged host process spawning.
Time-Boxed Fire-Fighting Mandates with Exclusion Ledgers
Human-minted time-boxed emergency grant with 0600 UID-verified exclusion ledgers, AST hunk trace attribution, and automatic hold re-arming on failure.		 aida mandate aida-cli-lib/src/gate/mandate.rs UID 0600 + AST Trace Bounds emergency ship authority to traced scope and restores holds if shipping fails.
Cross-Vendor Grant Expiry Hook Notices (2h / 30m / Expired)
Sub-2-second locked ledger hook injects grant countdown context into Claude Code, Codex CLI, and Antigravity (--client agy).		 aida role expiry aida-core/templates/hooks/aida-grant-expiry-notice.sh Locked Notice Ledger Delivers deduplicated expiry warnings across all three agent harnesses without blocking tools.
Event-Driven Attested Reviewer Daemon (aida review watch)
Spawns independent reviewers on branch push without waiting for CI, with 2-slot shared capacity reservation and stale-head author notifications.		 aida review watch aida-cli-lib/src/review_watch.rs 2-Slot Shared State Starts code review immediately on push while bounding concurrent reviewer processes.
Symlink-Hardened Commit-Pinned Verdict Files (O_NOFOLLOW)
Every verdict reader pins the non-symlink directory and reads bounded, singly-linked regular files by file handle with FIFO watchdog protection.		 aida review-verdict aida-cli-lib/src/gate/review_verdict.rs O_NOFOLLOW / O_NONBLOCK Refuses symlink, hardlink, FIFO, or oversized verdict spoofing across all ship/merge readers.
4-Stage Pre-Merge Ship Gate with Typed Exit Codes (20–25)
Preflights review/corpus, mergeability, stale-definition, and hold gates before CI, then re-verifies under the branch merge lease.		 aida pr ship aida-cli-lib/src/ci_gate.rs Merge Lease Gate Fails closed with typed exit codes before and after CI settlement so stale verdicts never ship.
Rework-Only Merge Hold Clearance Policy
Allows current-head granted reviewer approvals to clear rework-only holds while retaining human holds for keystone, guided/operator, or sensitive specs.		 aida merge-hold aida-cli-lib/src/merge_hold.rs Double Spec Re-Read Automates ordinary rework recovery while preserving human sign-off on high-risk changes.
Classified CI Polling (Required vs Informational Workflows)
Polls classified CI check rows directly so pending/failed informational workflows do not block shipping while required checks always gate merge.		 aida pr ship --wait aida-cli-lib/src/ci_probe.rs Classified CI Probe Prevents non-blocking informational checks from stalling trunk integration.
Built-In Read-Only Host Constraint Verification Probes
Verifies version-1 constraint blocks using 6 closed Linux probes—never executing stored shell strings—reporting match/drift/unknown.		 aida verify constraints aida-core/src/constraints.rs 6 Closed Linux Probes Detects host/config drift without permitting arbitrary command execution from store data.
Multi-Language Criterion-to-Test Coverage & Red-Run Gate
Links acceptance criteria to Rust, pytest, JS/TS, and Go tests, and verifies tests fail before implementation (red-run) and pass after.		 aida criteria aida-cli-lib/src/criteria_red_run.rs Red-Run TDD Gate Proves traced tests exercise the requirement and are not tautological no-ops.
Post-Diff Spec Harvesting (aida harvest)
Analyzes a git diff or PR to propose missing acceptance criteria, micro-decisions, and ADRs via an opt-in ledgered checklist.		 aida harvest aida-cli-lib/src/harvest.rs Ledgered Opt-In Captures emergent implementation decisions back into the canonical spec store.
Store-Only Test Reconstitution Probe (aida reconstitute)
A blind agent regenerates tests using only the spec store (no code access) and compares them against real traced tests to expose spec gaps.		 aida reconstitute aida-cli-lib/src/reconstitute.rs Code-Blind Sandbox Measures whether acceptance criteria are specific enough to reproduce the test suite.
Clean-Room Regeneration Benchmark & Oracle (aida regen)
Exports a deterministic spec corpus and scores clean-room system rebuilds (R1/R2) inside bubblewrap with reference/stub controls and FIFO guards.		 aida regen score aida-cli-lib/src/regen.rs Bubblewrap + Controls Quantifies end-to-end specification completeness via discriminating oracle pass rates.
Multi-Trial Consensus Gap Detection (regen score --consensus)
Compares ≥3 independent R1 trials to separate true spec-store gaps (all-fail checks) from stochastic model misses, filing deduplicated draft specs.		 aida regen score --consensus aida-cli-lib/src/regen.rs ≥3-Trial Consensus Distinguishes underspecified requirements from single-run model variance.

02 / CURRENT WORKSPACE CRATES (7) & PLANNED aida-cli-lib DECOMPOSITION

7 Cargo Workspace Crates Today · 9 Planned Domain Extractions

Today, the root Cargo.toml defines 7 workspace crates (aida-core, aida-cli-lib, aida-cli, aida-tui, aida-server, aida-generate-types, and aida-crate). Because aida-cli-lib currently houses 1,192 src/*.rs files (78.3% of all Rust code), Section 2B outlines the planned 9-domain decomposition.

2A. Current Cargo.toml Workspace Crates (7 Crates in Production Today)

01 · aida-core Workspace Crate · 177 src/*.rs Files · 120.4k Code LoC

Spec Graph, Git-Canonical Object Store & Core Domain Models

The foundational domain library crate. Houses requirement models, the orphan-branch Git object store, hierarchical ID block allocation, pre-registered hypothesis locking, host constraint probes, mailbox delivery, and pooled worktree primitives.

  • Git-Canonical Object Store (object_store.rs, oplog.rs, git_ops.rs): Per-requirement YAML/JSON objects on aida-store with store writer locks, private-ref fetches, and union merges.
  • Domain Models & Graph Walk (models.rs, graph_walk.rs, hypothesis.rs): Typed specs, transitive dependency/impact traversal, and pre-registered hypothesis locks.
  • Distributed Node & Hub Primitives (block_allocation.rs, store_hubs.rs): Tree-ordered CAS ID block dispenser and confirmed-tip mirror fan-out.
  • Built-In Constraint Probes & Templates (constraints.rs, templates/): 6 closed Linux verification probes plus embedded master templates for 59 skills and 22 hooks.
Core library backing all CLI, TUI, and Server operations Explore CLI Surface ↓
02 · aida-cli-lib Workspace Crate · 1,192 src/*.rs Files · 675.6k Code LoC

CLI Command Dispatch, Autonomous Orchestrator, Gates, MCP & Regen

The primary application library implementing 163 of the 165 top-level CLI command families: queue/drain orchestration, review watch, PR ship gates, C7 seat authority, bubblewrap containment, stdio MCP server, and clean-room regeneration scoring.

  • Terminator Plugin Installer (aida terminal install terminator, terminal_cmd.rs): Installs the AIDA Terminator plugin as a user-local helper.
  • Autonomous Drain & Queue Engine (queue_cmd.rs, drain_batch.rs, compete.rs): Multi-phase implement → review → rework → ship pipelines and multi-vendor arena runs.
  • Review Watch, Verdicts & Ship Gates (review_watch.rs, gate/review_verdict.rs, ci_gate.rs, merge_hold.rs): Pre-CI reviewer dispatch, O_NOFOLLOW verdict validation, and 4-stage ship gates.
  • Containment, Mandates & Authority (contained_boundary.rs, gate/mandate.rs, role_cmd.rs): Kernel sandboxing, C7 seat locks, and UID-checked emergency mandates.
  • Clean-Room Regen, Reconstitution & MCP (regen.rs, reconstitute.rs, mcp.rs): Held-out oracle scoring, blind test reconstitution, and stdio MCP server.
Owns 163 CLI Command Families (see Section 2B for planned 9-crate split)
03 · aida-tui Workspace Crate · 32 src/*.rs Files · 20.1k Code LoC

Ratatui + PTY Terminal UI Shell & Session Multiplexer

Dedicated terminal user interface built on ratatui, crossterm, portable-pty, and vt100 that PTY-hosts interactive coding agent sessions alongside live spec and queue panels.

  • Embedded PTY Agent Host (aida tui, pty.rs, app.rs): Hosts live interactive agent sessions inside a split-pane terminal UI with VT100 escape-sequence rendering.
  • Signal-Safe Terminal Restoration: Catches SIGTERM, SIGINT, and SIGHUP to restore raw terminal state cleanly.
Owns 1 CLI Command Family (tui)
04 · aida-server Workspace Crate · 12 src/*.rs Files · 12.6k Code LoC

gRPC & HTTP/REST Remote Service Daemon

Provides network-accessible gRPC (tonic + pure-Rust protox compiler) and HTTP/REST (axum + tower-http) endpoints backed by the store, SQLite, or pooled PostgreSQL (r2d2).

  • Zero-Protoc Pure-Rust gRPC Build (build.rs, service.rs): Compiles Protocol Buffers in pure Rust via protox without requiring an external protoc binary.
  • Dual-Protocol Service (aida server, rest.rs): Serves gRPC, gRPC-Web, and REST JSON endpoints with CORS and tracing middleware.
Owns 1 CLI Command Family (server)
05 · aida-cli Workspace Binary Crate · src/main.rs + build.rs

Thin CLI Binary Entrypoint & Build-Stamp Harness

Compiles the aida executable binary, embedding git commit/build provenance via build.rs and delegating command dispatch directly to aida_cli::run() in aida-cli-lib. Also houses workspace-level CLI integration test suites under aida-cli/tests/.

Binary target: aida Delegates to aida-cli-lib
06 · aida-generate-types & 07 · aida-crate 2 Workspace Utility Crates · 2 src/*.rs Files

TypeScript Schema Codegen (aida-generate-types) & Library Facade (aida-crate)

aida-generate-types (aida-generate-types/src/main.rs) generates TypeScript type definitions from Rust domain structs via ts-rs. aida-crate (aida-crate/src/lib.rs) provides the top-level publishable crate facade re-exporting aida-core.
