EXECUTIVE BRIEF / THE GOVERNED SOFTWARE FACTORY

Delegate the work.
Retain the control.

AIDA preserves the intent behind the system people and agents build together. Keep working conversationally with your coding agent; retain both the implementation and a durable record of requirements, decisions and rationale. Configurable governance and autonomy support deeper delegation when needed.

People develop, review and collaborate. AIDA-aware agents perform routine CLI/MCP operations in the background, preserving intent as implementation progresses. Teams configure agent defaults, work protocols, delivery modes and supported workflow policy around their operating model.

That shared record supports maintenance, enhancement and handoffs long after the original conversation ends.

The problem it addresses

Coding agents increase output. Coordinating several agents adds another challenge: preserving decisions, avoiding conflicting work, verifying changes independently and knowing what was authorized. AIDA provides the operating structure around those agents.

What makes it governed

  • Versioned specs and decisions; code-to-spec traces.
  • Defined advisor, implementer, reviewer and integrator responsibilities.
  • Independent review verdicts tied to exact commits.
  • CI and merge gates, seat grants and time-boxed mandates.

A practical first evaluation

  1. Describe one bounded change to an AIDA-aware agent and agree the acceptance criteria.
  2. Start with supervised delivery.
  3. Inspect the change, review evidence and handoffs.
  4. Delegate suitable work to autonomous delivery as the evidence justifies it.

The management case: make human attention deliberate, make delegated authority explicit, and keep a record connecting intent to the resulting change.

Available today as alpha software on Linux. Supports Claude Code, Codex CLI and Antigravity; harness capabilities differ. Runs under a shared Unix user, without a multi-human security boundary. Production deployment requires separate policy and automation. AIDA does not claim a measured ROI or universal unattended delivery.
