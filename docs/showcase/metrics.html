03 / DO NOT CONFUSE THE DATA WITH THE REPORT

Recorded. Derivable. Not yet supported.

Available reports

Cycle time, trailer coverage, supported usage/cost reporting, drain telemetry and operational diagnostics have existing command surfaces. Missing evidence stays unknown.

Derivable, not a finished report

Per-change review rounds, rework ratios, lines changed per spec and a meaningful estimate-versus-execution comparison need additional joins or reporting policy.

Not established

Feature-duration forecasting, measured hours saved and equivalent-human-effort ROI are not supported claims. AIDA does not infer them from agent token counts or runtime.

The overview retains a dated 28 October 2026 repository snapshot. Those numbers are historical examples, not current performance promises. This page is a capability explanation, not a live telemetry display. Source coverage, attribution and rate-table freshness must accompany any report.

04 / THE PEOPLE IN THE PROCESS

Human contribution
is more than CLI activity.

People develop the system, pair with agents, make design choices, review changes and work with collaborators. AIDA preserves the intent behind that work. Most routine command calls come from agents, so command frequency is not a measure of human productivity or involvement.

The durable record gives a future maintainer context for a decision and gives a collaborator a shared starting point. Reporting adds evidence about the delivery process; it does not replace the judgment or maintenance value of that record.
