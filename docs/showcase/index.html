01 / THE SHIFT

02 / INSIDE THE FACTORY

A repeatable path. A durable record.

A team of agents.
A system of responsibility.

AIDA coordinates the lifecycle around the coding agents you choose. Each role has a job. Each handoff carries context.

01 DEFINE

Advisor

Clarifies intent, prepares acceptance criteria and selects how the spec should run.

↳ Spec + decisions
02 BUILD

Implementer

Works against the spec, changes code and validates the result in an isolated worktree.

↳ Change + tests
03 VERIFY

Reviewer

Independently checks the change against its acceptance criteria and records a verdict.

↳ Verdict at a commit
04 INTEGRATE

Integrator

Lands approved work through the applicable CI, review and authority gates.

↳ Gated merge
✳

Shared intent survives the handoff. Specs, relationships and history live in a Git-backed store. Operational records preserve the evidence around reviews and merges.

03 / SELECTABLE AUTONOMY

ONE PROJECT. DIFFERENT LEVELS OF DELEGATION.

Choose where
people stay in the loop.

Run a dark factory for bounded work. Keep people close to consequential decisions. Choose the execution mode per spec.

DARK FACTORY MODE

Delegate the lifecycle.

Agents implement, test, independently review and merge approved, authorized work. People set the intent, acceptance criteria and limits. Exceptions escalate.

A GOOD FIT

A bounded fix with clear acceptance criteria and no unresolved design decision.

WHO DOES WHAT
  1. Define intent & limitsHuman
  2. Implement & testAgent
  3. Independent reviewAgent
  4. Merge through gatesAgent

Routine human coding and code review are removed from the execution path. Review, CI and authority gates remain.

Ⅱ

Some work needs a decision first. decide blocks execution until the pending decision is resolved. It sits outside the autonomy ladder.

04 / THE CONTROL LAYER

BEYOND A PROMPT AND A PULL REQUEST

Built for the work
between the agents.

A / MEMORY

Intent that persists.

Versioned requirements, decisions and relationships give the next agent a place to start. Trace comments connect code to the spec that justified it.

Requirements · Decisions · Traceability
B / COORDINATION

Parallel, with boundaries.

Queues, worktrees, leases and role-specific sessions coordinate multiple workers. Mail and handoffs carry context across session boundaries.

Queues · Worktrees · Sessions
C / ASSURANCE

Review with a record.

Independent reviewers assess acceptance criteria. Verdicts attach to exact commits, and merge gates check the evidence and applicable holds.

Review · CI · Merge gates
D / AUTHORITY

Delegation with limits.

Seat grants and time-boxed mandates define authorized actions. Work outside delegated authority waits for the appropriate decision.

Grants · Mandates · Escalation
