# Testimonials

First-hand accounts of using AIDA, kept as dated files. These are **experience
reports** — from operators and from the agents that operate AIDA — not marketing
copy. They are meant to be objective, warts included, to help someone deciding
whether to adopt AIDA.

- `2026-09-12-llm-field-report.md` — an LLM's field report from operating AIDA
  across a multi-day session (Claude, product seat): what added value, where it
  added friction, and an inferred view of the human operator's experience.
