# STORY-441 — Archive concept + recent-terminal-by-default

Date: 2026-05-24 · Specs: STORY-441 (subsumes TASK-507) · Status: Plan · Complexity: Medium

## Summary

Today aida history/list/search hide every Completed/Rejected via is_terminal_status_str (TASK-64). The check hides freshly-shipped specs the moment they're bumped — exactly when the human wants visibility. The Requirement model + SQLite cache already carry an `archived: bool` column; STORY-441 wires it up + adds archived_at + bulk sweep + auto-sweep.

Conceptual pivot: status = lifecycle state; archived = view-level "no longer current context" flag. Two Completed specs can differ: one shipped yesterday (visible by default), one 6 months ago (archived, hidden).

## Key decisions (8 total, full plan in chat 2026-05-23)

- D1: archived_at as Option<DateTime<Utc>> (not HlcTimestamp) — matches existing field convention
- D2: REMOVE is_terminal_status_str default-hide entirely; archive flag replaces it
- D3: aida archive / unarchive as top-level commands (symmetric with aida punt)
- D4: Auto-sweep in handle_pull_command, gated on [archive].auto_after_days config (off by default)
- D5: ArchiveFilter enum (NonArchivedOnly/ArchivedOnly/Both) replaces include_archived bool
- D6: --archived / --all mutually exclusive on list/history/search; --all re-purposed to "include archived"
- D7: Auto-sweep clamps at 7 days minimum (defeats the feature otherwise)
- D8: --dry-run on bulk sweep prints plan without writing
