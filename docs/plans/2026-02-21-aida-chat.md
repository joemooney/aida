# AIDA Chat: Requirements-Aware AI Chat for PMs/Stakeholders

## Summary
Web-based chat UI that streams AI responses from the Claude API with full requirements context for PM/stakeholder Q&A. Spec IDs in responses auto-linked via existing LinkedMarkdown component.

## Architecture
- **Backend**: `aida-server/src/chat.rs` — POST /api/v2/chat streams SSE events via Claude API proxy
- **Frontend**: ChatPage component with useChat hook, raw SSE parsing via ReadableStream
- **Context**: System prompt built from `build_project_context()` + `build_all_requirements_summary()`
- **Model**: Defaults to claude-sonnet-4-20250514, overridable via AIDA_CHAT_MODEL env var
