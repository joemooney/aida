# AIDA User Guide — retired

> **This guide has been retired.** It was a `v0.1.0`-era snapshot and had
> drifted broadly out of date (removed commands, wrong environment variables and
> type prefixes, an old 4-state / 5-type model, and sections describing the
> native desktop app that was extracted from this repo on 2026-05-02). Rather
> than maintain a second, weaker copy of the CLI reference, it now points at the
> current, maintained docs.
